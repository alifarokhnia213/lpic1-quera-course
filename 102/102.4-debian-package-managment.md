# Use Debian Package Managment

Candidates should be able to perform package managment using the Debian package tools:
- install, upgrade & uninstall Debian binary packages.

- find packages containing specific files or libraries which may or may not be installed.

- obtain package information like version, content, dependencies, package integrity and installation status (whether or not the package is installed).

- awareness of apt. 

### Terms & utilities
- `/etc/apt/source.list`
- `dpkg`
- `dpkg-reconfigure`
- `apt-get`
- `apt-cache`

# Concept of package managment system
In the last 20 years we didn't have to compile packages manually in 99% of cases.

GNU-Linux is the predecessor of what we call the Appstore these days. All major distros have huge archives of pre-compiled software and are called their repositories and a kind of package manager software that takes care of searching in these repositories, installing software binaries from them from them, finding needed dependencies and installing them, resolving conflicts, and updating the system and already installed software.

Debian distrobutions use .deb format files as their packages and they use tools like `apt-get`, `dpkg`, `apt` and other tools to manage them. Debian packages have name convention which is: `<Name>-<Version>-<Release>-<Architecture>.deb`, like for example: `tmux-3.2a-4build1-amd64.deb`.

## Repositories
But where these packages come from? How does OS know where to look for deb packages? The short answare is a Repository. Each Distrobution has its repositories of packages. it can be on a disk, a network drive, a collection of DVDs, or most commonly a network address on the Internet.

On Debian systems the main configuration locations are: `/etc/apt/source.list` and `/etc/apt/sources.list.d/`. We can update the sources information by `apt-get update`. this piece of command will check all the sources specified in the configs and update the information about the latest software available there. This command won't actually upgrade the software, it only updates the information about the packages themselves.

## How does a command like "apt" or "yum" Automatically installs?
Any of major Distros have a huge list of useful packages; we call these, repositories of software. some distrobutions like Redhat based ones, may not let any packages easily get a place in their repositories, but some like Aarch may be much more open and have a huge repository. for example, to install VLC you certainly may need a couple of packages to get installed, so you get the executalbe itself from the repository and whatever dependency it has alongside it; after that everything is fetched to your system, it is able to install the software and configure the software based on fetched config files. these steps can be done by user but are mainly done by package managers.

## Installing Packages
Say you wanna install a terminal multiplexer called "tmux"; if it is on repositories it's enough to tell the package manager to simply do it:
```bash
sudo apt install tmux
```

### Note that
- `apt` or `apt-get` will ask for confirmation (Y or n).

- `apt` or `apt-get` resolves dependencies, it knows what is needed and installs them.

- Debian packages are `<packageName.deb>`.

- if you only want a dry-run/simulation:
```bash
apt-get install -s tmux
```

- and this will only download the files needed into the cache without installing them:
```bash
apt-get install --download-only tmux
```

- or even autoremove whatever is not needed anymore:
```bash
apt-get autoremove
```

- removing a package will not remove its dependencies.

- if removing a package's dependency you'll get a warning about what will be removed alongside this package.

## Searching for packages
If you're using the apt suit, the search is done via `apt-cache` or simply you can use the general `apt`:
```bash
apt-cache search "tiny window"
apt search grub2
```

## Upgrading
For upgrading a single package:
```bash
apt-get install tzdata
```

For upgrading whatever is installed:
```bash
apt-get upgrade
```

Or going to a newer version of distribution:
```bash
apt-get dist-upgrade
```

**Note that:** Like most other tools, you can configure the default configs at: `/etc/apt/apt.conf` and there also is a program named "apt-config" for this purpose.

## Reconfigure packages
Debian packages can have configuration actions that will take after the package is installed. this is done by `debconf`. for example tzdata will ask you about the timezone settings after you installed it. if you want to reconfigure a package that is already installed you can use the `dpkg-reconfigure`:
```bash
dpkg-reconfigure tzdata
```

## Package information with dpkg
The underlaying tool to work with `.deb` files is the "dpkg". it is your to-go tool if you want to do manual actions on a deb package. the general format is:
```bash
dpkg <options> <action> <package> 
```

**Some common actions are**:
- -c or --contents: Show the content of a package.
- -C or --audit: Search for broken installed packages and propose solutions.
- --configure: reconfigure an installed package.
- -i or --install: install or upgrade a package; it won't resolve/install dependencies.
- -I or --info: show info.
- -l or --list: list all installed packages.
- -L or --listfiles: list all files related to this package.
- -P or --purge: remove the package and its configuration files.
- -r or --remove: remove the package, keep the configurations.
- -s or --status: display status of a package
- -S or --search: search and see which package owns this file.

## Common apt-get options
- autoclean: Remove unused packages.
- check: Check DB for issues.
- clean: Clean the DB, you can do `clean all` to clean everything and start fresh.
- dist-upgrade: Major upgrade; checks for newer version of OS.
- install: Install or upgrade packages.
- remove: Removes a package.
- source: Install the source of a package.
- update: Updates the information about packages from repositories.
- upgrade: Upgrade all packages.

**Note**: in some cases a package is installed but without proper dependencies (say using dpkg) or an installation is interrupted for any reason. in these cases a `apt-get install -f` might help; "-f" stands for "fix broken".

## Common `apt-cache` options:
- depends: Show dependencies.
- pkgnames: Show all installed packages.
- search: Search for packages.
- showpkg: Show info about a package.
- stats: Show statistics.
- unmet: Show unmet dependencies for all installed packages or the one you specified.

## Notes
- Package managers automatically fetch executable, its needed libraries and packages, and system specific configuration files, and finally they install what you want.

- If we go on `/etc/apt/source.list` on a debian based distro, we are able to see repository addresses, starting by `deb`, the address, and at its end the arguments like `main` or `restricted`.

- If we specify only `main` at the end of repo address in configuration file, the system will only fetch main software which is more secure.

- In `source.list` there are lines only for security updates in formats like: `deb https://security.ubuntu.com/ubuntu jammy security main`, this can be useful when you don't want to completely update a software for compatability reasons and only want to update its security features.

- When running `apt update` it will only update the system's cache of software existing in repository placed on `/var/cache/apt/`; and when upgrading somthing or the system, the utility checks the cache for wheter somthing is upgradable.

- Some corporations may have their own repository of software, so it is essential to know how to add new repositories to the system. on debian based systems we add a separated file containing the address, to `/etc/apt/sources.list.d/` directory and it will be automatically added to main configuration which is in `/etc/apt/source.list`.

- There are even more tools; tools with fancy GUI or text-based tools and user interface tools like "aptitude"

- `apt-get --download-only` will only download the package alongside everything else but doesn't install it; but `apt-get download` will only and only download the package itself and nothing else.
